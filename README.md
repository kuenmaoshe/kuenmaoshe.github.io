# Shakoshako 猫舍官网 · 维护指南

网站地址：**https://kuenmaoshe.github.io**
仓库地址：**https://github.com/kuenmaoshe/kuenmaoshe.github.io**

网站是纯静态页面，托管在 GitHub Pages 上，**免费、无服务器、无数据库**。
所有内容（小猫、种猫、新闻、家长反馈、设置）都来自一个 Excel 文件：**`data/kittens.xlsx`**。

维护有两种方式，改的是同一份数据：
- **网页后台**（推荐，手机可用）：https://kuenmaoshe.github.io/admin.html —— 见下面第一节
- **直接改 Excel**：下载 → 修改 → 上传回仓库 → 约 1 分钟后网站自动更新

## 一、日常维护：网页后台（推荐）

打开 **https://kuenmaoshe.github.io/admin.html**（网站页脚也有「后台管理」入口），
登录后即可在手机或电脑上直接增删改小猫、种猫、家长反馈、常见问题和设置，点「保存并发布」，
网站约 1 分钟后自动更新。**照片直接选图上传，会自动压缩并生成缩略图，不需要自己处理图片。**

### 第一次使用：生成登录令牌

后台靠一个 GitHub 令牌代你提交，所以需要先生成一次（之后浏览器会记住）：

1. 用**猫舍的 GitHub 账号**登录 github.com
2. 打开 [Fine-grained tokens → Generate new token](https://github.com/settings/personal-access-tokens/new)
3. **Repository access** 选 `Only select repositories` → 勾选 `kuenmaoshe.github.io`
4. **Permissions → Repository permissions → Contents** 设为 `Read and write`
5. Expiration（有效期）按需要选（例如 1 年），生成后复制那串字符，粘贴到后台登录框

令牌只存在你自己设备的浏览器里。手机丢了或想作废，去 GitHub 设置里 Revoke 即可；
令牌到期后后台会提示重新登录，按上面步骤再生成一个就行。

### 后台能做什么

| 页面 | 能改什么 |
|---|---|
| 待办 | 打开后台自动列出要处理的事：该打疫苗的猫、临近出发的猫、缺照片/生日/新家地址的数据，点击直达编辑页（纯自动，无需维护） |
| 小猫 | 新增/删除小猫，改花色性别名字、在售状态、交易阶段（咨询中/已付定金/已付尾款/已接猫，仅后台可见）、生日、新家地址、爸妈；管理照片顺序与封面；填「小猫日记」（定新家/疫苗/血清/出发日期、体重记录、出发照片） |
| 种猫 | 新增/删除种猫，改名字角色花色，上传照片或 mp4 视频 |
| 家长反馈 | 新增/删除反馈，选对应小猫、写内容、配图 |
| 常见问题 | 增删改 FAQ，调整顺序 |
| 设置 | 成立日期、新家礼包、访客地区 |
| 统计 | 自动生成的数据看板：在售/已售/本月成交、月度成交趋势、热门花色排行、新家地区分布、交易阶段分布 |

几点须知：

- 删掉一只猫或一张照片，只是网站不再显示，**原文件仍留在仓库里**，可以通过「从已有照片选」找回
- 保存前如果有小猫缺花色或照片，会弹窗提醒（这类猫不会显示在网站上）
- 如果仓库同时被别处改动过，保存时会提示，建议先点「重新载入」再改一遍
- 上传照片自动压到 1300px（约 200KB）并生成 500px 缩略图，与站内现有图片规格一致

## 一之二、老办法：直接改 Excel（仍然可用）

1. 打开仓库页面 → 进入 `data` 文件夹 → 下载 `kittens.xlsx`（点文件名 → 右上 Download）
2. 用 Excel / WPS 修改并保存
3. 回到仓库 `data` 文件夹 → **Add file → Upload files** → 拖入同名文件 → 点绿色 **Commit changes**
4. 等 1 分钟左右，刷新网站即可看到更新（浏览器缓存顽固时按 Ctrl/Cmd+Shift+R 强刷）

新增照片同理：进入 `assets` 文件夹 → Upload files 上传图片 → 在 Excel 里填 `assets/文件名.jpg`。

两种方式改的是同一份数据（`data/kittens.xlsx`），可以混用；后台保存时会保留 Excel 里的
全部工作表和列顺序，「填写说明」表也原样保留。

## 二、Excel 各工作表说明

### 1️⃣ 小猫数据（每行一只猫）
| 列 | 填法 |
|---|---|
| 花色 | 银虎斑、棕虎斑、蓝虎斑、红虎斑、烟灰色、纯黑色、纯蓝色、凯米尔色（可加前缀：浅色银虎斑、银虎斑补丁…） |
| 性别 | 弟弟 或 妹妹 |
| 图片路径 | `assets/文件名.jpg`，可填多张（逗号分隔）；第一张是卡片封面，点开侧边面板可滑动看全部 |
| 是否出售 | 是 = 已到新家（已售）；否 = 可预订（在售） |
| 生日 | `2026-04-05` 格式；**网站按生日自动计算并显示月龄**，会随时间自动增长；留空则不显示年龄 |
| 新家地址 | 已售的猫填城市/省份/国家（如 北京、黑龙江、荷兰），会显示在卡片上，并在"猫舍动态"的世界地图上自动打点 |
| 爸爸 / 妈妈 | 填「种猫」表里的名字；填了以后网站出现按种公/种母筛选，点击小猫卡片会跳转并高亮它的父母 |
| 名字 | 可选；填了以后卡片标题显示名字（如 驺驺），花色性别变成小字副标题 |

- 行的顺序不影响展示：网站自动按 **可预订在前、年龄从小到大** 排序
- 删除一行 = 从网站移除该猫；"关于我们"里的在售/已售数量自动统计

### 2️⃣ 种猫
名字 / 角色（种公 或 种母）/ 花色 / 图片路径。
图片路径可填**多个**（逗号分隔），第一个是封面；`.mp4` 视频会自动循环播放；点击卡片可放大浏览全部照片和视频。
种猫媒体文件建议放 `assets/parents/` 文件夹（现有：阿泽 aze-1/2.jpg，小辫子 xiaobianzi-1/2.mp4）。

### 3️⃣ 新闻
（该板块已从页面移除，此表暂不使用，保留备用。）

### 4️⃣ 家长反馈
日期 / 小猫名字 / 内容 / 图片路径（可选，多张用逗号分隔）。
**小猫名字要和小猫表的「名字」一致**：点击该小猫的卡片，侧边面板里会显示它的照片、爸妈信息和家长反馈（图片可点击放大）。反馈照片建议放 `assets/feedback/`。

### 5️⃣ 常见问题
问题 / 答案。显示在购买流程下方的可折叠 FAQ；当前 6 条答案为草拟，请核对修改。

## 三、图片文件的存放规则

| 位置 | 用途 |
|---|---|
| `assets/` | 小猫照片、环境照片、家长反馈图片（网页引用格式统一为 `assets/文件名.jpg`） |
| `assets/parents/` | 种猫的照片和视频 |
| `assets/world-map.svg` `assets/china-map.svg` | 自动生成的地图，**不要改动** |
| `assets/vendor/` | 网页运行所需的库文件，**不要改动** | 
| `data/sheets.json` | 由 GitHub Action（或后台保存时）自动从 Excel 生成，**不要手改** |

- 建议图片宽度 1000–1400px、文件 200–500KB：太小在大屏上模糊，太大拖慢加载（现有图片已统一压到约 1100px / 200KB）
- 文件名建议用英文/数字，不要带空格
- 单个文件不能超过 100MB（GitHub 限制），视频建议压到 10MB 以内

## 四、网站自带的自动功能（无需维护）

- **三语切换**（中/EN/KO）：右上角按钮，猫名、月龄、界面文字自动翻译
- **日/夜间模式**：右上角 ☀/☾ 按钮，访客的选择会被记住
- **访问统计**：Flag Counter 按国家统计（明细：https://info.flagcounter.com/UpWw ，请收藏）。**访客地图的国家级和中国省份级光点都每天自动更新**：国家来自 Flag Counter，省份由网站前端对每位中国访客做 IP 定位后累加到免费计数服务（Abacus），每日 GitHub Action 一并汇总进 `data/visitors.json`。「设置→访客地区」仍可手动补充额外地点（自动数据从 2026-08-21 起累计，之前的访客不含在内）
- **小猫足迹地图**（在售幼猫区标题右侧，"小猫足迹"标签在左、地图在右；手机端折叠为「🐾 小猫足迹」按钮，点开才显示）：从"新家地址"自动生成，支持国内省市和常见国家；如果填的地名没打出点，是坐标库里没有——告诉 Claude 加一个即可
- **月龄计算 / 数量统计 / 筛选（状态·性别·年龄·种公·种母，默认显示可预订）**：全部自动

## 五、注意事项与排错

- **不要改 `index.html`**（网站主文件，改动需要懂代码）；内容维护只碰 Excel 和图片
- Excel 的**列顺序和表名不能改**（程序按位置读取），加猫加行即可；J–N 列为可选的日记里程碑：定新家日期、出发照片、打疫苗日期、血清检测日期、出发日期（未来日期显示为「预计出发」）、体重记录（如 2026-07-30 · 6.2斤，多条逗号分隔）
- 如果改完 Excel 网站没变化：① 等 2 分钟再强刷 ② 检查图片路径拼写 ③ 检查生日格式
- 如果 Excel 损坏或路径全错，网站会退回显示上一次的内容，不会白屏
- 环境/喂养板块的照片（花园×3、室内×2、生骨肉、营养品、猫砂×2）已于 2026-08 全部换成高清版。**同名覆盖图片后网站可能仍显示旧图**（浏览器缓存），需要在 `index.html` 里把该图的 `?v=` 版本号 +1 才对所有访客生效——这一步找 Claude 处理，或自己强刷验证
