# Shakoshako 猫舍 · 微信小程序版

官网 https://kuenmaoshe.github.io 的小程序版本，**数据和图片与官网完全共用**：
改 `data/kittens.xlsx` → 提交到 GitHub → 官网和小程序同时更新，小程序不需要重新发布。

---

## 一、在微信开发者工具中打开

1. 下载安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版即可）
2. 打开工具 → **导入项目** → 目录选择本仓库的 **`weapp` 文件夹**（不是仓库根目录）
3. AppID 处：
   - 有小程序账号：填自己的 AppID
   - 只是本地预览：点 **「测试号」** 或选「不使用云服务 + 测试号」
4. 点确定，模拟器里就能看到首页

> 注：`project.config.json` 里的 appid 目前是占位的 `touristappid`，导入时按上面选择即可覆盖。

## 二、真机预览前必须做的一步（重要）

小程序默认只允许访问「已备案并配置白名单」的域名。本项目要读取
`https://kuenmaoshe.github.io` 上的数据和图片，两种做法：

- **本地开发/预览**：开发者工具右上角 **详情 → 本地设置 → 勾选「不校验合法域名…」**，模拟器和真机预览即可正常加载。
- **正式发布**：在[微信公众平台](https://mp.weixin.qq.com) → 开发 → 开发管理 → 服务器域名，把
  `https://kuenmaoshe.github.io` 加进 **request 合法域名** 和 **downloadFile 合法域名**。
  （GitHub Pages 域名无法通过备案的话，需要把数据和图片放到一个已备案的域名，或改用小程序云开发存储。）

## 五、与官网的差异（技术限制）

- **没有网页版的滚动动效和视差**：小程序渲染层不同，改为静态排版 + 原生预览交互。
- **世界地图打点**改为地区标签列表。
- **访问统计**（Flag Counter）不适用于小程序，已移除。
- **社交平台图标**改为文字说明（小程序内不能直接跳外部 App）。

## 六、发布流程（有小程序账号后）

1. 在微信公众平台注册小程序，拿到 AppID，填进项目
2. 配置服务器域名（见第二节）
3. 开发者工具点 **上传** → 在公众平台「版本管理」提交审核 → 通过后发布

## 七、数据兜底与本地化

`utils/fallback.js` 是从 `data/sheets.json` 生成的**内置兜底数据**（6.4KB，42 只小猫）。
网络不可用时（包括审核环境域名未配置的情况）自动启用，保证页面不空白。

重新生成（数据有较大变动后建议更新一次）：

```bash
python3 - <<'PY'
import json
js = json.load(open('data/sheets.json'))
keep = {k: js[k] for k in ['__first','小猫数据','种猫','常见问题','设置'] if k in js}
open('weapp/utils/fallback.js','w',encoding='utf-8').write(
  '// 内置兜底数据：网络不可用时（含审核环境）保证页面完整\n'
  '// 由 data/sheets.json 生成，勿手改\n'
  'module.exports = ' + json.dumps(keep, ensure_ascii=False, separators=(',',':')) + ';\n')
PY
```

### 图片是否也要本地化？

实测数据（当前 43 只猫 + 种猫 + 环境喂养图）：

| 做法 | 体积 | 说明 |
|---|---|---|
| 全部图片本地（560px q70） | 约 **4.7MB** | 需拆分包（主包≤2MB、单分包≤2MB、总量≤20MB）+ `preloadRule` 预下载 |
| 只放封面图本地（420px q68） | 约 **2.8MB** | 列表能看，点开大图仍需网络 |
| 只放静态图（环境/喂养/logo） | 约 **0.5MB** | 主包放得下 |
| 只放数据（当前做法） | **6.4KB** | 文字完整，图片仍需网络 |

**代价**：图片一旦打包进小程序，新增小猫、换封面都必须**重新提交审核**（1–3 天），
就失去了"改 Excel → 1 分钟自动更新"的核心优势。种猫视频（4.9MB）也无法本地化。

**推荐顺序**：
1. **小程序云开发**——不需要备案、不需要配域名，免费额度（5GB 存储 / 月 5GB 下行）远够用，
   把 `sheets.json` 和 `assets/` 传到云存储即可，自动更新能力完整保留。
2. 备案域名 + 国内对象存储——改 `utils/data.js` 里的 `BASE` 一行即可。
3. 全本地打包——只有在前两条都走不通时才考虑。
