# 小程序提审自查报告

对照《微信小程序平台运营规范》《小程序服务类目》做的逐项检查。
分三类：**🔴 提审前必须解决**、**🟡 建议处理**、**🟢 已通过**。

## 🔴 必须解决（不解决基本会被驳回）

### 1. 服务类目与主体资质 —— 最大风险
猫舍的核心业务是**活体宠物交易**，这在小程序里属于受限范围：

- **个人主体做不了**。个人主体开放的类目非常有限，涉及商品交易/商家自营的类目均未开放。必须用**企业主体**（营业执照）注册小程序。
- **需要先确认类目能否申请**。"宠物活体销售"不在常规开放类目里，可能的路径有两条：
  - **路径 A（推荐，风险最低）**：定位成**猫舍品牌展示**，不做线上交易，类目选 `IT科技-企业服务` 或 `生活服务-其他生活服务`；页面只展示猫咪与猫舍信息、引导线下咨询，**不出现价格、不做下单和支付**。当前代码就是这个形态。
  - **路径 B**：确实要做线上销售，需要申请电商相关类目，并按平台要求补交资质（营业执照，可能还需要《动物防疫条件合格证》等）。这条路要先向微信客服确认活体动物能否上架。
- **动作**：注册企业主体小程序 → 在公众平台「设置-基本设置-服务类目」按路径 A 选类目 → 如被要求补资质，按提示提交。

> ⚠️ 我无法替你确认平台当前对活体动物销售的最新口径。**提审前请通过公众平台「客服-在线咨询」直接问一次**，把答复截图留存。

### 2. 服务器域名无法备案 —— 数据会加载不出来
小程序正式版**只能请求已在公众平台配置的域名**，且域名必须**已完成 ICP 备案**。

- 现状：数据和图片都来自 `https://kuenmaoshe.github.io`（GitHub Pages），**境外域名，无法备案**，因此**无法配置进合法域名**。
- 后果：开发者工具勾选"不校验合法域名"时一切正常，但**提审和正式版会直接请求失败**，页面只剩静态内容，小猫列表为空 → 审核判定"功能不完整"驳回。
- **可选方案**（择一）：
  1. **小程序云开发**（最省事）：开通云开发，把 `sheets.json` 和图片放进云存储，代码改用 `wx.cloud`，**不需要备案和域名配置**。
  2. **买个已备案的域名 + 国内对象存储**（阿里云 OSS / 腾讯云 COS），把 `data/` 和 `assets/` 同步过去，改 `utils/data.js` 里的 `BASE` 常量即可。
  3. **数据内置**：把 `sheets.json` 打包进小程序，图片也放本地。缺点是每次更新数据都要重新提交审核，失去"改 Excel 自动更新"的优势。

  → 推荐方案 1 或 2。方案 2 只需改一行 `BASE`。

### 3. 隐私保护指引必须配置
2023 年起所有小程序都要在公众平台填写《小程序用户隐私保护指引》，否则相关接口会被限制。

- 本小程序**不收集任何用户个人信息**（无登录、无授权、无表单），用到的
  `setClipboardData` / `makePhoneCall` / `previewImage` / 本地缓存都不属于需授权的隐私接口。
- **动作**：公众平台 →「设置-服务内容声明-用户隐私保护指引」→ 选择"**不收集任何用户信息**"提交即可，几分钟通过。

## 🟢 已符合

- **无诱导分享**：分享按钮为系统菜单触发，不强制、不给奖励。
- **无虚拟支付**：全站无支付、无购物车、无价格。
- **无外部跳转**：没有 `web-view`，不引导下载 App。
- **无测试/占位内容**：所有文案、图片均为真实内容，无 lorem、无"测试"字样。
- **功能完整可用**：三语切换、日夜模式、筛选、图片预览、指南页均可离线于数据独立运行（静态板块不依赖网络）。
- **页面标题规范**：首页「Shakoshako 猫舍」、指南页「缅因猫喂养指南」，与内容一致。
- **无违规词**：文案中无"最佳""第一""国家级"等绝对化用语作为宣传语（"最佳"仅出现在喂养建议的口语描述中，如"羽毛逗猫棒最佳"，属经验分享非广告承诺，风险低；若审核挑刺可改为"更推荐"）。
- **代码规范**：无 `eval`、无动态下发代码、无外部 JS。

## 提审顺序建议

1. 注册/切换到**企业主体**小程序，拿到 AppID
2. 配置**服务类目**（先问客服确认活体宠物口径）
3. 解决**数据域名问题**（云开发或备案域名）→ 配置 request / downloadFile 合法域名
4. 提交**隐私保护指引**（选"不收集"）
5. 绑定**客服人员**
6. 开发者工具「上传」→ 公众平台「版本管理」→ 提交审核，**在"功能页面路径"里填首页，备注里写明"猫舍品牌展示，不涉及线上交易"**
