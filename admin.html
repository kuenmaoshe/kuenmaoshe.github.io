还没有令牌?点这里看怎么生成
  1. 用猫舍的 GitHub 账号登录 github.com
  2. 打开 Settings → Developer settings → Fine-grained tokens → Generate new token
  3. Repository access 选 Only select repositories → 勾上 kuenmaoshe.github.io
  4. Permissions → Repository permissions → Contents 设为 Read and write
  5. 有效期(Expiration)按需要选,例如 1 年;生成后复制那串字符粘到上面
令牌只保存在这台设备的浏览器里,不会上传到别处。若手机丢失或令牌泄露,去 GitHub 设置里把它 Revoke 即可。
